♞ Chess Proxy

♞ Play Chess.com on GitHub Pages

GitHub Pages hosts this static frontend, while your deployed Cloudflare Worker or Render backend from this repo relays Chess.com HTTP requests, cookies, and live-game WebSockets.

Need a free backend URL? Deploy in 1 minute:
  • Cloudflare Workers (Recommended): Run npx wrangler deploy in this repo (uses src/index.js) and paste your https://*.workers.dev URL above.
  • Render: Connect this GitHub repo as a Node Web Service (npm start, uses server.js) and paste your https://*.onrender.com URL above.
  • Shareable link: Append ?backend=https://your-worker.workers.dev to this GitHub Pages URL to auto-connect on any device.
Tip: If your browser blocks third-party cookies inside iframes (e.g., Safari or Brave Shields) and Chess.com login won't stay signed in, click ↗ Direct to open Chess.com directly on your proxy backend.
